## About

**The Unblocked Initiative (TUI)** is a collaborative group of developers working together to improve the unblocked-games community, exchange ideas, and create projects.

Built around shared ownership and democratic decision-making, the initiative gives its members a voice in the group's direction and encourages collaboration over isolated development.

Our website serves as the central hub for introducing the initiative, sharing updates, showcasing projects, and documenting our plans for the future.

## Our Mission

- **Connect developers** — Bring creators together to share ideas and work collaboratively.
- **Improve the community** — Contribute to a better unblocked-games ecosystem.
- **Showcase projects** — Give visibility to the things our members are building.
- **Encourage participation** — Create opportunities for people to contribute and get involved.
- **Plan for the future** — Track ideas, goals, and upcoming developments through a shared roadmap.

### Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Hate-yndicate/the-unblocked-initiative.git
   ```

2. Enter the project directory:

   ```bash
   cd the-unblocked-initiative
   ```

3. Open `index.html` using a local development server, such as the VS Code Live Server extension.

4. Keep JavaScript enabled for the interactive features to work correctly.

### Deployment

The live website is hosted at the following address:

**[theunblockedinitiative.p2pgames.workers.dev](https://theunblockedinitiative.p2pgames.workers.dev/)**

The repository includes a `wrangler.jsonc` configuration file for the project's Cloudflare deployment workflow. Deployment settings and account access may need to be configured for your environment.

## Contributing

We believe good projects grow through collaboration.

If you're contributing to the website or related projects:

- Keep changes consistent with the existing design and structure.
- Test interactive elements and navigation after making changes.
- Keep project information and roadmap entries up to date.
- Explain significant changes clearly in your commits or pull requests.
- Avoid committing credentials, API keys, account data, or other secrets.

For project-specific contribution rules, check the relevant repository before submitting changes.
